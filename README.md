# M.E.M. Kids – samlet opdatering

Statisk hjemmeside. Åbn index.html eller udgiv filerne i roden på GitHub Pages.

## Sider
- index.html: fælles indgang og introduktion
- boern.html: eksisterende lege, fortælling og gratis bog
- unge.html: grænser, stemme, tempo, digitale spørgsmål og kontinuitet
- voksne.html: grundlag, læring, trivsel, offentlige systemer og AI
- bankeren.html: fortællinger og udviklingsspor til skærm og fysisk companion
- laering.html: læringsprincip og VR-vision
- science-sandbox.html: lokal kopi af den eksisterende browserprototype

Ingen nye eksterne scripts, login, API-kald eller indsendelse af tekst.
Sanselige øvelser er lokale skitser. M.E.M.I.-kernen er ikke koblet til siden.
PDF'er og bogillustrationer har særskilte vilkår; se LICENSE og boeger/BRUGSVILKAAR.txt.
