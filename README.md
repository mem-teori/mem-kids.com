## Bog og læsevejledning

*Når verden taler tilbage* (9–12 år) ligger i børnerummet ved `boern.html#bogen`.
Forsiden har en lille henvisning, og voksenindgangen linker til læsevejledningen.
Begge PDF-filer ligger lokalt i `boeger/`; omslaget ligger i `assets/`.
